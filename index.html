Detection rules

  • Brute force: 5 or more failed logins from one IP within 5 minutes (T1110.001)
  • Password spraying: one IP failing against 4 or more different usernames (T1110.003)
  • Suspicious success: a successful login right after 3 or more failures from the same IP (T1078)
  • SQL injection: SQL keywords or tautologies in web requests (T1190)
  • Cross-site scripting: script tags or event handlers in requests (T1190)
  • Path traversal: ../ sequences or access to system files (T1083)
  • Scanner activity: known scanner user agents or many 404 errors from one IP (T1595)

Educational project with fictional sample data. Everything is processed locally in your browser. Detection rules are simple examples and are not a replacement for a production SIEM.
